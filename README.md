# mystudyroom

个人学习网站：以手绘书本、阅读笔记与文具构成的学习书房。

## 在线访问

https://zhongxintong123456.github.io/mystudyroom/

## 当前功能

- 仅保留四门课程：CS231n、CS336、Princeton 机器人学、MIT 扩散模型。
- 四个课程介绍页，可打开各自官方课程网站的学习资料。
- 首页四个跨页、四本课程书与可移动便利贴。
- 首次使用引导与页脚“使用指南”入口。
- 固定封面和书签，只卷动纸页；保留窗帘、树影、文字微动、杯中热气与音符。
- 台灯暖光与动效暂停；便利贴位置保存在当前浏览器。
- 电脑与手机布局；无固定日期、周计划或寒假安排。

## 运行

无需安装依赖。通过任意静态服务器提供当前目录，例如：

```sh
python3 -m http.server 8765
```

## 发布

GitHub Pages：从 `main` 分支的根目录发布；`.nojekyll` 禁用 Jekyll 构建。
所有资源使用相对路径，支持 `/mystudyroom/` 项目地址。

## 插画

`assets/` 中的透明 PNG 为本项目通过 AI 生成的插画素材。参考图片未包含在此仓库中。
网站无需 API Key，不连接后端，便利贴位置与外观偏好仅保存在访问者自己的浏览器。

## 动画

使用 GSAP 3.13.0（https://gsap.com/），保留发行文件中的许可声明。尊重系统的“减少动态效果”设置。

# mystudyroom

个人学习网站：以手绘书本、阅读笔记与文具构成的学习书房。

## 在线访问

https://zhongxintong123456.github.io/mystudyroom/

## 当前功能

- 五个学习方向：基础入门、CS231n、CS336、机器人学、扩散模型。
- 八周轻量学习路线与课程官方链接。
- 一篇完整的 Python 入门阅读。
- 字号调整、读完标记，本机浏览器保存进度。
- 电脑与手机布局。
- 书名跟随鼠标浮窗；三张可自由移动、重叠并保存位置的便利贴。
- 书本入场、微风翻页、茶杯热气、飘动音符，以及点击台灯切换暖光。
- 一键暂停微风与持续动效；音符仅为视觉装饰，不自动播放声音。

这是持续完善中的第一版，后续章节尚未全部编写。

## 运行

无需安装依赖。通过任意静态服务器提供当前目录，例如：

```sh
python3 -m http.server 8765
```

## 发布

GitHub Pages：从 `main` 分支的根目录发布；`.nojekyll` 禁用 Jekyll 构建。
所有资源使用相对路径，支持 `/mystudyroom/` 项目地址。

## 插画

`assets/` 中的三张透明 PNG 为本项目通过 AI 生成的插画素材。参考图片未包含在此仓库中。
网站无需 API Key，不连接后端，阅读状态仅保存在访问者自己的浏览器。

## 动画

使用 GSAP 3.13.0（https://gsap.com/），保留发行文件中的许可声明。尊重系统的“减少动态效果”设置。
